Reviewer decoder

What is easy to misread on first pass

Technical readers should not have to guess which numbers are validation, which are deploy summaries, and which files were actually submitted. This is the cheat code menu before the methods.

0.5799 is not the final hidden-260 score

It is the honest leave-one-out RAE on the 253 released Analog Set 1 compounds. The 260 rows were still blind at submission time.

The final 513 file is truth-hybrid

After Analog Set 1 labels were public, the submitted CSV used those 253 released pEC50 values directly and used model predictions only for the remaining 260 blind rows.

RAE is the primary score

RAE = sum(|y - yhat|) / sum(|y - mean(y)|). Lower is better. A mean-only predictor scores 1.0 in the evaluated set.

pEC50 direction matters

pEC50 is -log10(EC50 in M). Higher pEC50 means stronger functional activation potency.

"Clean base models" means leakage-filtered

The late prediction pool was screened against the released 253; vectors with near-perfect 253 behavior, including MAE below 0.05 on the released rows, were excluded before the final deploy blend.

Validation regimes are not interchangeable

Scaffold CV, clean holdouts, 253 LOOCV, distance-weighted 253 clusters, and deploy-mode in-sample checks answer different questions. The page labels them separately on purpose.

Data and metric prep

Exactly what entered the model

The page's claims are all anchored to explicit data partitions and metric regimes. This is the boring-but-vital part where the lab coat gets buttoned correctly.

Raw data roles

Dataset Size Role
CRC dose-response train 4,139 compounds Primary pEC50 regression labels for base training.
Counter-assay train 2,859 compounds PXR-null/selectivity signal for auxiliary heads and artifact checks.
Single-concentration screen 21,003 rows / 10,870 compounds Functional activity prior converted into P(active).
Analog Set 1 unblind 253 compounds Final correction validation; later included in deploy training for the 260.
Still-blind test partition 260 compounds Rows that actually needed predictions in the final submission.
Boltz rich-z embeddings 4,139 train + 513 test Target-aware protein-ligand structural signal.

Standard featurization

  1. Load challenge CSVs through src/pxr/data.py and normalize column names.
  2. Parse/standardize SMILES with RDKit utilities in src/pxr/chem.py.
  3. Build Morgan ECFP4 fingerprints: radius 2, 2048 bits.
  4. Add RDKit 2D descriptors, then median-impute descriptor missing values.
  5. Compute Bemis-Murcko scaffolds for scaffold-aware splits.
  6. Project Boltz rich-z interaction embeddings with PCA-24 for the final structural component.

Single-conc label prep

The single-dose screen was not treated as fake pEC50. It was converted into a binary activity prior per SMILES: 

active =
  max(log2_fc_estimate) > 0.5
  and min(fdr_bh) < 0.1

An LGBMClassifier on Morgan + RDKit features produced P(active). That probability only nudged or gated the final pEC50 prediction; it did not replace dose-response labels.

Test partitioning and metric

The 513 challenge test rows were split by molecule name: ub_idx for the 253 rows present in the Phase-1 unblind file, and bl_idx for the remaining 260 rows. Final submission assembly used truth for ub_idx and model predictions for bl_idx. 

RAE = sum(abs(y_true - y_pred))
    / sum(abs(y_true - mean(y_true)))

RAE is set-relative: the denominator changes with the validation set. That is why a 253 LOOCV RAE, a clean-train-holdout RAE, and a public leaderboard RAE should not be mixed as if they were the same scoreboard.

Method, with receipts

The final model is a small band of orthogonal signals

The final predictor kept the pieces that addressed distinct failure modes: base ensemble shrinkage, local analog cliffs, target-aware structure, and functional activity evidence from the single-dose screen.

Blend formula

base_blend =
  0.40 * meta_stacker
+ 0.20 * tanimoto_knn
+ 0.10 * combined_2d
+ 0.30 * boltz_richz

shifted = base_blend
        + 0.10 * (P_active - 0.5) * 2

if P_active < 0.15
   and boltz < 3.2
   and shifted < 3.5:
       pEC50 = 3.0

Component-by-component method

Component Training / deploy input Why it exists Validation note
Meta-stacker 29 prediction streams after dropping obvious leakers, including vectors with 253 MAE below 0.05. Combines diverse GBM/GNN/embedding models without trusting any single model. 253 LOOCV stream used for honest validation; 260 stream used for deploy.
Tanimoto kNN residual Nearest measured analogs in Morgan fingerprint space. Corrects local analog neighborhoods where the global stack smooths cliffs. Kept as a component, not a standalone predictor, because novel scaffolds weaken kNN.
Combined 2D correction Morgan ECFP4 + RDKit descriptor prediction stream. Stable low-variance ligand-only QSAR signal. Receives only 10 percent final weight because much of its signal is redundant.
Boltz rich-z PCA-24 of Boltz protein-ligand interaction embeddings plus base predictions. Adds target-aware structural context missing from pure ligand descriptors. Weighted at 30 percent in the final blend after 253 validation.
Single-conc P(active) Classifier trained on aggregated single-dose screen labels. Provides orthogonal functional biology: active/inactive evidence from an assay axis. Improved 253 RAE from 0.5977 to 0.5799 after shift plus inactive gate.

Validation gauntlet

The model iterated by passing the right test for each claim

Validation was the steering wheel. Architecture claims went through scaffold or clean holdout checks. External-data claims went through mirror datasets. Final correction claims went through 253 LOOCV and integrity audits.

Validation dictionary

Regime Rows scored What it was allowed to decide Key number shown here
Scaffold CV 4,139 CRC train rows split by scaffold Early model viability and leakage-resistant baseline screening. Random splits were roughly 0.1 RAE too optimistic.
Clean analog holdouts Train-derived, scaffold-disjoint holdouts Whether a late feature/data axis transferred beyond the visible 253. Clean holdout RAE 0.4746; use only within this regime.
253 LOOCV Released Analog Set 1, one compound held out at a time Final correction selection and honest Analog Set 1 validation. Final stack RAE 0.5799.
Deploy-mode 253 Released 253 scored after fitting deploy components with those labels available Sanity check for deploy behavior, not an honest validation metric. In-sample RAE 0.5636.
Distance-weighted 253 253 clustered by Tanimoto distance Pessimistic check for chemical interpolation optimism. Random 0.5431 versus distance-weighted 0.6406.
Final 513 submitted file 253 released truth rows + 260 model-predicted rows Actual challenge submission artifact. No hidden-260 RAE was available at submission time.

Validation surfaces by claim type

Claim Validation surface Decision rule
New learner or representation Scaffold CV, Tanimoto-OOD, clean train holdout Promote only if it survives chemistry shift, not just random split comfort.
External or synthetic data Mirror datasets, matched clean holdouts Keep only data that adds the right axis, not noisy pEC50 cosplay.
Final 253 correction 253 LOOCV, distance-weighted 253 clusters Require an honest held-out score and a pessimistic transfer check.
Deploy prediction array Integrity audit and OOF/provenance checks Reject suspicious te_*.npy files before they reach the submission ladder.

Project arc

From "try every architecture" to "find better information"

The repository is big because the search was intentionally broad. The final model is narrow because the validation gates made the signal hierarchy clear.

Level 1

Try basically everything

GBMs, GNNs, Chemprop, kNN, foundation embeddings, physics descriptors, external data, calibration, routers, and many ensembles got a turn under the lights.

Level 2

Stop only stacking

Once molecule-only features saturated, the campaign shifted to synthetic labels, weak labels, external assays, and public data.

Level 3

Bake in biology

Single-concentration PXR response became a functional activity prior instead of fake dose-response truth.

Level 4

Add target structure

Boltz rich-z gave the final model target-aware interaction signal that ligand-only descriptors did not fully contain.
