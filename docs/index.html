Method, with receipts

The final model is a small band of orthogonal signals

The final predictor kept the pieces that addressed distinct failure modes: base ensemble shrinkage, local analog cliffs, target-aware structure, and functional activity evidence from the single-dose screen.

Blend formula

base_blend =
  0.40 * meta_stacker
+ 0.20 * tanimoto_knn
+ 0.10 * combined_2d
+ 0.30 * boltz_richz

shifted = base_blend
        + 0.10 * (P_active - 0.5) * 2

if P_active < 0.15
   and boltz < 3.2
   and shifted < 3.5:
       pEC50 = 3.0

Validation surfaces by claim type

Claim Validation surface Decision rule
New learner or representation Scaffold CV, Tanimoto-OOD, clean train holdout Promote only if it survives chemistry shift, not just random split comfort.
External or synthetic data Mirror datasets, matched clean holdouts Keep only data that adds the right axis, not noisy pEC50 cosplay.
Final 253 correction 253 LOOCV, distance-weighted 253 clusters Require an honest held-out score and a pessimistic transfer check.
Deploy prediction array Integrity audit and OOF/provenance checks Reject suspicious te_*.npy files before they reach the submission ladder.

Project arc

From "try every architecture" to "find better information"

The repository is big because the search was intentionally broad. The final model is narrow because the validation gates made the signal hierarchy clear.

Level 1

Try basically everything

GBMs, GNNs, Chemprop, kNN, foundation embeddings, physics descriptors, external data, calibration, routers, and many ensembles got a turn under the lights.

Level 2

Stop only stacking

Once molecule-only features saturated, the campaign shifted to synthetic labels, weak labels, external assays, and public data.

Level 3

Bake in biology

Single-concentration PXR response became a functional activity prior instead of fake dose-response truth.

Level 4

Add target structure

Boltz rich-z gave the final model target-aware interaction signal that ligand-only descriptors did not fully contain.
